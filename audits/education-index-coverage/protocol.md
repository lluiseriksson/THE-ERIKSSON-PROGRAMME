# Source coverage in the requirements-engineering education selection register

Use the exact publicly deposited selection register, version DOI 10.5281/zenodo.24407666. It labels entries by status, title and bibliographic source. A retained representative may come from one index while a duplicate from another index represents the same study. Count accepted titles with and without crediting those duplicate records. Determine all minimum-cardinality source sets that cover every retained title in this particular exported register. Report the loss on omitting each source; a title whose only evidence is one index supplies an explicit indispensability witness. This is retrospective register coverage, not the recall of a bibliographic database in the world or a guarantee about future searches.

Freeze recognition before measurement. Use page geometry to reconstruct cells, joining wrapped and page-split title lines. Primary ID is Unicode NFKC casefolded and whitespace-collapsed title; dehyphenate a line-end only when its two renderings can be compared explicitly. Confirm all accepted rows visually against page images. Credit a second source only for a matching title in an Accepted or Duplicated row. Flag any Rejected/Accepted classification conflicts separately. Report a second pass using punctuation-insensitive letter/digit tokens and deterministic casefolding. Different titles, editions and same-author studies remain separate unless a primary DOI, author/version record or explicit duplicate linkage justifies uniting them. Do not distribute the full register; derivative counts, short identifiers, provenance and retrieval instructions suffice.

Falsifier: if the entire result is the same with and without duplicate-index credit across both matching rules, report the equality as a negative finding. Stop making completeness claims if page extraction cannot assign status, source and title unambiguously; bound the effect of unresolved linkage or abandon the result.
