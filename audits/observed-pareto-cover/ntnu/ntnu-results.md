# A finite-library certificate for the NTNU drainage example

The public SWMMLIDopt example contains 200 candidate configurations with 13 design parameters and two exported objectives. The accompanying R code records the rounded construction cost in thousands and a simulated peak outflow. This audit uses those exported figures. It does not rerun a hydraulic model or bound error relative to unobserved designs. The example and the 2026 preprint concern different studies.

For each budget equal to the cost of a library member, require a portfolio to contain a design at or below that cost with peak flow at most delta L/s above the best accessible library member. A single portfolio must satisfy all budgets. The resulting smallest possible maximum excess at portfolio sizes 1, 2, 3, 5 and 10 equals **544.856, 269.9095, 180.9240, 107.9319 and 52.6721 L/s**. Representative one-based row numbers are in budgets.json. For example the five-design solution uses rows 2, 169, 73, 20 and 6. Any strictly smaller tolerance needs at least six designs. For the ten-design portfolio a strictly smaller tolerance needs at least eleven.

All 200 exported cost–peak pairs are distinct and nondominated. In particular, no two have equal reported cost: if two did, one would be dominated or the pairs would be identical. R computes the first objective as round(total_cost/1000). Distinct rounded values preserve strict ordering of the original costs under the same deterministic monotone rounding convention. Thus this comparison between designs does not require equality of raw and rounded costs. A prescribed external budget in currency units can still change which design is affordable when it falls inside a rounding bin. The README and interface label currencies differently; none of the results here converts them to money.

**Derivation.** Sort the nondominated rows by increasing cost, giving strictly decreasing peaks. For a given nonnegative tolerance, the least-cost point requires a witness. At the earliest point not covered by a previous witness, the most effective affordable witness is that point itself, since its peak is the lowest in its prefix. Exchanging an alternative affordable witness for it after the preceding groups have already been covered cannot hurt any later point. This gives the minimum number by successively taking the earliest uncovered points. With strict inequalities the same argument gives the lower bounds above. An independent computation partitions the sorted front into k contiguous groups. A group from h to j has excess peak[h]-peak[j]. Minimizing over the final boundary gives the exact minimax value. The code compared both calculations and tested every raw row against the returned witnesses.
