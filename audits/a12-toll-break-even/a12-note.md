# A route-ranking test for the Austrian A12 infrastructure surcharge

**Scope.** For the 2026 truck tariff, compare one kilometre on the surcharged Kufstein–Innsbruck/Amras stretch to x kilometres at the ordinary Austrian distance tariff. This conditional toll comparison excludes special section charges, VAT, fuel, driver time and route availability. It is an algebraic test of a pricing model; the two distances need not correspond to a feasible detour.

**Inputs.** Section 3 raises the infrastructure component by 25%. If I is that component and T the ordinary total per kilometre, the A12 kilometre costs T+I/4. The break-even ordinary distance is therefore r=1+I/(4T). For x below r the ordinary kilometres cost less; for x above r the A12 kilometre costs less. The executable matches all 24 axle/emissions totals to ASFINAG's 2026 truck table before evaluating any ratio. Four axles denotes the four-or-more tariff. CO₂ class 5 is emissions-free. The model and operator inputs are pinned to the 2026 release, which distinguishes infrastructure, CO₂ and air/noise. [Regulation §3](https://ris.bka.gv.at/eli/bgbl/ii/2025/298/P3/NOR40273503) · [Operator rates](https://go-maut.at/go-maut-bezahlen/tarife-go-maut/) · [Kabir, carbon-cost v0.99.0](https://doi.org/10.5281/zenodo.24406888)

**Fleet-independent approximation.** Across the 24 cells the ratio ranges from 7641/6548 (1.166921, two axles, CO₂ class 1, Euro 0–III) to 5905/4756 (1.241590, four or more axles, CO₂ class 5). A distance ratio of 1.22 therefore gives opposite rankings at the two endpoints. A class-blind factor x applied to the total ordinary toll has fractional error x/r−1. For x between the smallest and largest r, the worst absolute error is max(x/r_min−1,1−x/r_max). Outside this interval moving toward it improves the maximum. Equating the endpoint errors gives the unique minimax multiplier 2*r_min*r_max/(r_min+r_max)=45120105/37503268. Its unavoidable worst relative error is 290668/9375817 (about 3.1002%). This limit applies only to a common multiplicative approximation across these 24 tariff cells. Route-aware calculation retaining the infrastructure component has no such approximation error.

**Reproduction.** Use the operator table and the file ending in tariffs/data/at/at-2026-01-01.orct.json in the versioned release above. The second copy under orct/testdata is a fixture and encodes the factor differently. The checked release dataset uses a gross multiplier of 1.25. The extraction script writes at.json and operator.json in a working directory. Run carbon-threshold.py there with Python 3. The JSON output contains each rate, effective surcharge and exact break-even ratio. Only the official figures needed to verify the calculations are used. No coordinates or OpenStreetMap geometry are redistributed.
