# ReViCo image scores under a different order of language aggregation

All twenty vision models in Table 1 admit integer confusion counts matching the six published scores when precision and recall are averaged equally over Chinese and English before taking their harmonic mean. The manuscript at d12d1bb4 separately examines averaging each language's F1. Nineteen rows admit counts under that convention. Which convention was actually used requires information beyond the rounded table.

The denominators are 376 erroneous and 354 clean Chinese images, and 266 erroneous and 233 clean English images. Each vector in harmonic.json lists detected Chinese and English errors, corrected Chinese and English errors, and Chinese and English false positives on clean images, in that order. The detection and correction metrics share the false-positive counts. For either task compute precision and recall in each language with an additive denominator constant of 1e-8, average each over the two languages, then compute F1 from the two averages. Each of the resulting six values falls within the printed rounding cell. For Qwen3-VL-2B the vector is [62, 17, 9, 15, 35, 1]. These are example counts, not recovered predictions.

To reproduce on Colab Linux, place the parent directory's tables.json in the same directory as harmonic_verify.py and lang_harmonic.cpp, then run python3 harmonic_verify.py. The search nominates integer counts using floating point. The program checks each nominated vector's six scores using rational arithmetic. The existence claim needs one verified witness per model.
