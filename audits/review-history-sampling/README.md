On Colab Linux run weights.py and coverage.py separately. Each script checks the digests of two public CSVs and writes /content/archive.zip. Retain or extract each archive before running the next script. To reproduce bounds.json, call bounds.bounds with the parsed coverage.json and serialize the result using json.dumps(..., default=str). The scripts use the Python standard library, with inputs from Syed at https://osf.io/nmhbf/. Only aggregate results are distributed.
