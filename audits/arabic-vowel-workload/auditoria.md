# Selective insertion of Arabic case vowels at a fixed workload

This audit uses Adel F. Amer's published aggregate test counts on the Prague Arabic Dependency Treebank, deposited on 20 November 2026 (https://doi.org/10.5281/zenodo.24407151). The archive checksum and primary download URL are in source.json. Obtain zenodo_p2.zip from that record, check the SHA-256, then run python3 padt-frontier.py alongside the archive. Compare the resulting JSON with frontier.json.

On 4,327 eligible test positions, the published 0.77 threshold fills 1,730 positions and makes 31 errors. Keeping the 1,706 fills at threshold 0.80 retains 23 errors. Of the 24 additional positions between 0.77 and 0.80, eight were wrong. The 422 positions with scores from 0.60 to below 0.70 contain 121 errors. Selecting exactly 24 positions uniformly without replacement from those 422 instead gives 23 + 24(121/422) = 6305/211 expected automatic errors, about 29.88 at exactly the same workload. An exchange argument shows this is optimal among policies using only the published bands, keeping all cue-rule decisions, using identical probabilities within each band and assigning no fills below 0.60. Sorting bands by their empirical error rates fills the lowest first. This is retrospective; the ranking uses the test labels.

A whole-document lottery between the published thresholds 0.6 and 0.8 with probability 24/2461 on 0.6 has the same expected number of fills and 73571/2461 expected errors, but its realized workload varies. Neither alternative measures the writer's performance on deferred positions. For the exact-budget swap, if the writer's mean error probability on the removed 24 positions exceeds that on the replacement population by at least 1/3 - 121/422, the expected gain in total final correctness disappears.

A prospective check should select the alternative band using development labels alone, freeze that decision, and assess the same budget against the fixed source threshold on untouched evaluation material. The existing test split has already been inspected. It can diagnose transfer from the development split but cannot itself supply fresh prospective evidence.
