# Two budgets for archived ML trials

Use the paper release of Wong (arXiv:2611.23678v1), commit 04551715c7b74184ec5446fdd1c3221aae557862. Restrict to all primary memory-arm campaigns for ResNet L40S, synthetic logistic regression and autoresearch Linux. Use the SHA-256 in the author's manifest for each file. Compare arms within task and labelled campaign seed. For the primary comparison require the same nonempty hash of the initial node state, the same nonempty training seed and the same recorded initial incumbent (which may be absent in both). Report other pairs separately, including any missing evidence or absence of valid scores.

For each pair of arms and each common integer k, compare best observed valid score in the first k attempted trials and in the first k valid, successfully scored trials. Use recorded validation AUC, synthetic validation score and bits per byte respectively, with lower better only for bits per byte. A failed attempt consumes one attempted-trial slot. It supplies no performance score. A valid discarded trial with a score counts as a scored trial. A prefix without a valid score is undefined. Report strict reversals separately from tie transitions and incomparable cases. The null is equal rankings at every comparable prefix. These descriptive results cannot identify a causal effect of memory or an expected effect on fresh runs.
