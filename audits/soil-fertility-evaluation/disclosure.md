# Which published margins identify the minority-class outcome?

In the three-decimal version of the [soil fertility evaluation](https://www.mdpi.com/2673-4591/163/1/114), fix 122 common cases and the 112 versus 111 accuracy counts. The least frequent class actually contains three cases. Releasing that number reduces 206 candidate recall pairs to two. Even revealing the full true support vector (3,58,61) allows the first method to miss all three while the second detects either zero or one (see the witness tables in the certificate). Knowing the numbers of true cases in each class does not identify which of those situations applies.

Consider the nine individual counts consisting of the three ordered true supports and the three predicted class counts of each method, taking their values from the source-precision reconstruction. None individually identifies both recalls. Exactly eleven inclusion-minimal subsets suffice, all of size two. For example, revealing that the middle class contains 58 true cases and the second method makes two predictions of the smallest class forces both recalls to zero. Revealing any two predicted column totals for the second method is another sufficient choice. Revealing only the predicted frequencies of the smallest class for both methods still admits four recall pairs. These are properties of this dataset and this dictionary of reportable counts. A direct per-class success count is outside this comparison.

The exhaustive search keeps the least-class diagonal and all predicted column totals for each method. It pairs tables only when the complete true support vectors agree. For each pair it marks the nine reported counts which coincide with the full-precision reconstruction, and computes the exact feasible recall set for all 512 possible disclosure subsets. Minimality follows by testing each one-field deletion from a sufficient subset; feasibility is monotone under deletion. Retaining every matching signature preserves every possible pair even when multiple confusion matrices share a signature. Where least supports tie both orders are eligible. The fixed test-cohort assumptions and the precise coarsening convention are those in the manuscript and rounding supplement (ordinary unweighted counts, not a sampling-bias assumption). The two enumerations share authoring context.

The machine-readable result includes the full subset-to-outcome mapping and integer witnesses for the main comparisons. This note supplements the earlier PDF and has its own revision.
