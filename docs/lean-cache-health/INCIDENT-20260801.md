## Minimum repair that restores signal

No remote rule was changed in this audit.  The owner should apply changes in
stages and should never make a path-filtered check required, because a skipped
required workflow can remain pending.

1. Immediately require the already ubiquitous `honesty` context, with strict
   up-to-date branch checking.  This gives one real, useful gate without
   claiming Lean compilation.
2. Add a dedicated, unfiltered Lean smoke workflow.  It must check out the
   public SHA, install the pinned toolchain, use an isolated package directory,
   run `lake update`, verify that the manifest did not change, run `import
   Mathlib` twice, build the minimum required project target, and run the PR #39
   oracle.  Make its stable job context required only after it is proven green
   on fresh runners.
3. Keep the full 623-manifest validator visible and failing until its historical
   debt is repaired.  Do not disable, weaken, or label it green.  To recover a
   useful merge signal meanwhile, add a separate regression gate that rejects
   any newly introduced manifest errors against a reviewed, committed baseline.
   Once all legacy errors are repaired, require the full validator and remove
   the temporary baseline.
4. Split the current control-plane job so the inherited manifest failure does
   not prevent the independent state, documentation, sanitation, and pytest
   diagnostics from running.

## Safe consumer handoff

Use only a fully verified, quiescent source.  Resolve and inspect both paths
before copying.  The destination must be new and ordinary; `/XJ` prevents
Robocopy from traversing junctions.  `/MIR` is deliberately absent.

```powershell
$source = 'C:\Users\lluis\AppData\Local\Temp\eriksson-push2\.lake\packages'
$destination = 'C:\absolute\new\clone\.lake\packages'
Get-Item -LiteralPath $source -Force | Format-List FullName,Attributes,LinkType
New-Item -ItemType Directory -Path $destination
Get-Item -LiteralPath $destination -Force | Format-List FullName,Attributes,LinkType
robocopy $source $destination /E /COPY:DAT /DCOPY:DAT /R:2 /W:1 /XJ /NFL /NDL /NP
$robocopyExit = $LASTEXITCODE
if ($robocopyExit -ge 8) { throw "Robocopy failed with exit $robocopyExit" }
pwsh -NoProfile -File scripts\check_lean_environment.ps1 `
  -RepositoryRoot C:\absolute\new\clone `
  -PackagesRoot $destination
```

Never use junctions; never recurse-delete a link or reparse point; never repair
the shared source in place; never copy from a package tree while Lake is using
it; never treat a cache hit as mathematical evidence.
