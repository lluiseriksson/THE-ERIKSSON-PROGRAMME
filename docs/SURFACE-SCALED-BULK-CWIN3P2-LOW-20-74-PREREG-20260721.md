# Candidate scaled-bulk CWIN=3/2 probe on β∈[20,74]

This is a new candidate-only probe, not a theorem certificate.  It freezes
the same executable as the high-order archive: `CWIN=3/2`, beta order 30,
t-order 37, 180 Arb bits, and `min_dt=1/100000`, with the moving domain

```text
beta ∈ [20,74],   t ∈ [3/5, π - (3/2)/beta].
```

Each production unit must have a byte-identical replay under one source HEAD,
an exact rational beta interval, an adjacent outward-rounded `trow` partition,
and strictly negative row upper bounds.  A manifest may record only candidate
scope.  Even a complete candidate union does not imply `(H_tail)`, because the
positive scaling identity preserves sign while changing weighted derivative
majorants.  No G2, G6, K2, or manuscript promotion is authorized by this probe.

The first feasibility unit is `[20,81/4]`; later units may be launched only
with the same frozen driver and a separately recorded manifest.
