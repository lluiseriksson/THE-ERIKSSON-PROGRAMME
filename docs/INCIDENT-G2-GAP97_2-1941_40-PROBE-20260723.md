# G2 narrow beta refinement probe: `[97/2,1941/40]`

The unchanged high-order CWIN=`3/2` sign-row driver was run on the first
registered gap with a narrow refinement
`[97/2,1941/40] = [48.5,48.525]`.  Production and replay both completed with
the frozen order-30/order-37, 180-bit Arb configuration and the unchanged
`min_dt=1/100000` stopping rule.  The pair is byte-identical (SHA-256 of each
file: `4b5c519488d2c1345bdfe8d52b700898360cbf73e3cad29141ca9e823a802a21`),
and contains 102 adjacent strict-negative t rows covering
`[3/5, pi_upper-(3/2)/(1941/40)]`.

The independent text/Arb integrity check is
`scripts/validate_surface_scaled_bulk_probe_unit.py`.  This is an exploratory
subinterval only: it was not a pre-registered terminal unit, no manifest was
created, and it carries no G2/G6 load.  The parent gap, the finite-beta union,
the sign-to-`H_tail` relay, and the final gate remain open.

The immediately adjacent refinement
`[1941/40,971/20] = [48.525,48.55]` was then run with the same production and
replay settings.  It also produced 102 rows with byte-identical transcripts;
the validator now checks both pairs.  This doubles the local candidate segment
but does not change its nonterminal status.

A third adjacent refinement, `[971/20,1943/40] = [48.55,48.575]`, also
completed with 102 production/replay rows under the same frozen settings and
is included in the validator.  A mistyped zero-width invocation with equal
endpoints failed immediately before this run; it produced no certificate.

For route sizing, the same driver was also attempted on the triple-width box
`[97/2,1943/40] = [48.5,48.575]`.  It did not emit a transcript within 180 s;
the timeout is retained as a negative design result and does not alter any
gate.
