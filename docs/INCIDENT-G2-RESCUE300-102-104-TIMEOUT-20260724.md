# Incident: rescue300 timeout on `[102,104]`

The preregistered 300-bit order-40/50 rescue driver was launched on
`[102,104]` with the same strict contract as the successful boxes below beta
102. The 1,800-second wall-clock budget expired before the adaptive cover
emitted a terminal transcript. No production/replay pair, row count, or
manifest was created.

This is an uncovered candidate interval, not a numerical disproof and not a
certificate. The finite-beta topology therefore remains certified only
through beta `102`; the sign-to-`(H_tail)` relay and G2/G6 gates remain open.
