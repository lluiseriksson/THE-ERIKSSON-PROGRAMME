1. BALANCED INTEGER TREE AND GEOMETRY

stays unchanged. Nodes have <=b children, root X, leaves singleton, and every
node's coordinate lengths differ by at most1 (hence aspect <=2).
At global depth k all nonempty coordinate intervals have length h or h+1,
h=max(1,floor(n/2^k)). A descendant hole I at depth k has side lengths in[h,2h].
Every positive clearance from I to any ancestor Q boundary is a union of
depth-k intervals, so is >=h. Use GLOBAL h, not min side of this particular I.

4. COMPRESSED COEFFICIENT-MASS PARTITION
Give each vertex weight w=a^-P. A tree node is heavy iff mass>t.
If root light, output root. Otherwise let L be terminal heavy nodes, B the
number of heavy nodes with >=2 heavy children. Heavy terminals are disjoint
and each mass>t, so L<=S(X)/t, and B<=L-1 by finite rooted tree counting.
Heavy nodes with exactly one heavy child form maximal unary chains; their
number is <=B+L<=2L-1. (Contract chains; each ends at a branching/terminal node.)
At unary Q->Q', the increment Q\Q' consists of <=b-1 light children, so has
mass <=(b-1)t. Greedily group consecutive increments along a chain until
their accumulated mass first reaches >=t; each group is a balanced ring
Q_i\Q_j with mass < b t. At chain end a residual ring has mass<t.
All closed groups across all chains are disjoint, so number<=S(X)/t;
residual groups number<=2L-1. At branching/terminal heavy internal nodes
output each light child cube (mass<=t). At heavy singleton terminals output
the singleton, whose variance is0. Such cubes/singletons number<=b(B+L).
These regions are disjoint and cover X; count <=1+(2b+3)S(X)/t.
Each nonsingleton has mass<=b t=(cG_D)^(-D/2), so its actual Neumann gap>=c.
The algorithm uses coefficients/tree only and never f.

5. RECTANGULAR OBSERVATIONS WITHOUT INTERFACE LOSS

coordinates in I, current coordinate below/above I, remaining coordinates
