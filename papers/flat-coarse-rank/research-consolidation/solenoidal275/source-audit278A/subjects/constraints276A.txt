2. EXACT REDUCTION OF ALL SIX CELL TYPES ON EACH SLICE
For residue r define sigma(r)=r if odd, r-1 modn if even. For fixed i put
 E_i(j)=V_sigma(i+j)(i,j),     W_i(j)=sum_(s odd)V_s(i,j).

through all n residues, each odd s occurs twice in sigma(i+j+x3). Hence
 sum_(x3=0..n-1)w(i,j,x3)=2W_i(j),
 sum_(x3=1..n-1)w(i,j,x3)=2W_i(j)-E_i(j).                (1)
Therefore every original row vanishes iff, for every i and every nonempty
cut interval I, both vector sums sum_I E_i=0 and sum_I W_i=0. The equivalence
uses the short-cell sum first and then the long-cell sum; no row is replaced
in an energy/penalty estimate and no normalization is lost in this zero test.
All factors are positive finite and original channel2 rows already vanish.

For X=E or W let P_i^X(k)=sum_(j=0..k-1)X_i(j), 0<=k<=n. The exact conditions

5. ELEMENTARY DERIVATION OF THE COST, INCLUDING ALL FACTORS
Fix odd s and y1=i. Plane vanishing implies V_s(i,j)=0 at both
j=s-i and j=s+1-i modulo n, because these are respectively A and B points
on x3=0. These are adjacent zeros on the y2 cycle. The complementary path
has L=n-1 edges and n-2 interior vertices, with both endpoints zero.
For ANY vector sequence z_0=z_L=0, write d_k=z_(k+1)-z_k. For1<=j<L,
 z_j=((L-j)/L)sum_(k<j)d_k-(j/L)sum_(k>=j)d_k,
so finite Cauchy-Schwarz gives
 |z_j|^2 <= [j(L-j)/L] sum_(k=0..L-1)|d_k|^2.
Summing j, using sum_j j(L-j)/L=(L^2-1)/6, gives
 sum_(k=0..L-1)|d_k|^2 >= [6/(L^2-1)]sum_(j=1..L-1)|z_j|^2. (6)
This is an elementary vector Dirichlet path estimate, not an optimal constant.
