2. Actual tight frame and finite angular bins.
Choose an orthonormal g-by2 matrix U with UU^T=P. A coefficient-only
deterministic choice is Gram--Schmidt on P e_1,...,P e_g, taking the first
two independent columns with positive normalization. Rank2 guarantees them.
Write u_alpha in R^2 for row alpha, w_alpha=||u_alpha||^2<=delta=2Lambda/g.
Then sum_alpha u_alpha u_alpha^T=I_2 and sum_alpha w_alpha=2.
Zero rows will receive root observations and require no angle or division.

Fix K=2048 and epsilon=1/256. Partition projective angles [0,pi) into
K half-open bins of length pi/K, with representative angle at each left
endpoint. Nonzero u_alpha defines an unoriented rank1 projector
P_alpha=u_alpha u_alpha^T/w_alpha and is assigned its actual bin.
Let P_l denote the representative projector. For rows in that bin,
 ||P_alpha-P_l||=|sin(theta_alpha-theta_l)|<=pi/K<1/512<epsilon.
Signs do not change projectors. Bin endpoint conventions and original-index
tie breaking remove ambiguity. This uses the elementary bound pi<4.
Let M_l=sum_(alpha in l)w_alpha and S_l=sum_(alpha in l)w_alpha P_alpha.

Discard every bin with M_l<32delta from nonroot allocation. Its positive
matrix is <=M_l I_2, so all discarded bins together cost at most32Kdelta I_2.

                 sum_regular S_l >=(1-32Kdelta)I_2.       (243.2)
No well-conditioned subset or matrix group has been assumed here.

3. Cumulative quantiles in each regular bin: actual disjoint groups.

All cuts exist because t_q<1 and the bin mass is M_l. Use the difference
between successive cut prefixes as the channels I_(l,q). Successive cuts
can coincide; an individual bin group may be empty. Different q groups
are disjoint, and all remaining rows receive roots.
If mu_(l,q) is that group's mass, prefix overshoots lie in [0,delta], so
              |mu_(l,q)-beta_q M_l|<=delta.               (243.3)
Using the actual maximum within the bin strengthens the same inequality.

B_total M_l+delta <(15/16+1/32)M_l=31M_l/32.
Thus remaining mass is >M_l/32; initially it is M_l, so the base case
is direct, without a false strict comparison of two empty sums.
If m_l rows are in this bin, every sorted remaining prefix has average
at least its remaining overall mean, which is >M_l/(32m_l).
The additional mass needed for the next cut is <=beta_q M_l, since the
preceding cut already reached t_(q-1)M_l. If it is nonpositive, the group
is empty. Otherwise the same finite-prefix argument as242 gives
                  |I_(l,q)|<=ceil(32m_l beta_q).

existing cut before the end; no nonexistent entries are counted. Summing

                   |I_q|<=32g beta_q+K,                 (243.4)
where I_q is the union of the actual I_(l,q). No positive minimum row
weight, scalar subset-mass condition or fractional channel is introduced.
