# A limitation of all six benchmark summaries

Consider four fixed rows with targets (0, 0, 2, 2), population standard deviation 1, and the fixed test set consisting of rows 1 and 3. One prediction vector is (0, 1, 2, 1). A second is (1, 0, 1, 2). The latter swaps predictions within each pair of identical target values. Both stay within the observed target range.

For both predictors the full-library MAE is 1/2, RMSE and relative RMSE are 1/√2, and R² is 1/2. The two correlations also agree. Both the prediction vectors and their midrank vectors are permuted within tied target classes, leaving their dot products with the centered target and its centered midranks unchanged. Directly, Pearson and Spearman correlations both equal 1/√2 in this example. On the specified test rows the first predictor is exactly correct, and the second has RMSE 1. The same target vector, the same subset, and the same six exact full-library metrics therefore admit opposite decisions at threshold 1/2.

More generally, partition rows by equality of the observed target value. Fix the predictions up to permutations inside each class. If a class has k rows in the specified test set, its minimum and maximum contributions to the test sum of squared errors are the sums of its k smallest and k largest squared errors. Each extremum is attained by assigning the selected predictions to the k test locations. Since the classes are disjoint their extrema add. This supplies a constructive finite test for whether opposite decisions can be produced without changing any of the six global scores. The permutations need not be attainable by training the same forest on the same features. The four-row example is an algebraic counterexample to global sufficiency, not evidence of an ambiguity in a particular archived forest.
