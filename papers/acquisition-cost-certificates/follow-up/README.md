# Reconstructing the follow-up analyses

The main paper’s `reconstruct.py` reconstructs the three evaluation populations from the public benchmark. In this directory, `two-moments.json` records a separate exact-rational test of the information in the two whole-library moments. Each row contains the property, seed, method, nominal training size and truth value of the uniform ambiguity certificate. `lemma.md` gives its proof. `six-summary-counterexample.md` gives a four-row example with identical values of all six global scores.

The executed Python payloads are in `executed-sources.zip`; their SHA-256 digests and the digests of the returned archives are in `run-hashes.json`. Each payload writes its output under `/content` and is intended for a fresh Linux Colab runtime. The moment calculation reads the archived error table at the pinned public Git commit and uses the retained case identifiers. Each forest reconstruction obtains the original data, row-index files and scoring definitions from that commit. It installs the exact scikit-learn version in a temporary directory, leaving the runner's NumPy and SciPy versions recorded in the output. Read access to GitHub is required for the public benchmark and read access to PyPI for the pinned wheel.

`probe.json` contains the fits for the two 100-row designs of MP21 formation energy at seed 2. `crossing.json` contains the larger active designs examined after the first fit missed the target. For each fit the full-pool dimensions, six observed and archived scores, common-subset score, selected hyperparameters and full residual-vector digest are retained in the return or its summary. Comparing the six scores tests the reconstruction at the resolution reported by the authors. It does not identify their individual historical predictions.

The restricted shared-scale check in `last-cell.json` retained one undecided case. The extended check in `scale-boundary.json` uses all eligible raw/relative RMSE pairs for that same target. The 3,920 intervals from the seven predictors share one normalization denominator in the original evaluator. Their intersection certifies failure for the active QM9 gap forest at 500 rows and seed 7. The numbers and the strict comparison are in `scale-proof.md`.

The last active fit at 5,000 training rows is recorded in `final.json`; the sequence of all four active fits is needed to locate its first crossing.
