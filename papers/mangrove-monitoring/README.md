# Monitoring a proposed mangrove planting

Source tables 7, 8 and 9 appear on printed pages 74 and 75 of Hafidhin, Kusmana and Rusdiana, DOI 10.29303/jppipa.v12i11.15691. The field design has not been run. The policy comparison holds initial budgets and the number of original planting positions fixed.

The three Python programs use only the standard library. On dedicated Colab Linux run each in a clean /content directory. census_budget.py creates feasibility.zip (result.json, archived here as census_budget.json). sampling.py creates sampling.zip and capacities.py creates capacities.zip. The JSON files retain exact rational values. Source-PDF identity is in primary.json. No third-party PDF is included. The two frame protocols test hypothetical planting registers, not measured field capacities.

The false certification probabilities refer to one prespecified all-success rule. They do not control repeated attempts or constitute empirical data on survival.
